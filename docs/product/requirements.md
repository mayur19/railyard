# Requirements

Functional (FR) and non-functional (NFR) requirements for Railyard. Priorities use MoSCoW (**M**ust, **S**hould, **C**ould, **W**on't for 1.0). Status is derived from the [backlog](../planning/backlog.md): a requirement is `implemented` only when every ticket that delivers it is `done`; otherwise it is `pending`. Traceability to code and tests lives in [requirements-traceability.md](requirements-traceability.md).

Summary: **110 functional requirements** (36 implemented, 74 pending) and **30 non-functional requirements** (17 implemented, 13 pending).
