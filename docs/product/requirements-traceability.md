# Requirements Traceability

Maps every functional requirement in [requirements.md](requirements.md) to its epic, delivering ticket(s) in the [backlog](../planning/backlog.md), the module that implements it and the test that proves it. For pending requirements the module and test columns read `planned`; the HTTP surface of most pending requirements already exists as a 501 stub in `apps/api/src/modules/pending/pending.routes.ts`, verified by `apps/api/test/runs.http.test.ts` ("answers every planned route with 501 and its ticket").

Paths are relative to the repository root. Test names in quotes are the `it(...)` titles.
